# Actividade 13 
E uma atividade prática de automação de testes para validar o sistema de suporte à vida de um habitat em Marte. 
O projeto utiliza Python, Pytest, Mocks, Selenium WebDriver, BDD e Integração com GitHub Actions.

## Tecnologias e Ferramentas Utilizadas
- **Pytest:** Para testes unitários,integração, parametrização e tratamento de exceções.
- **Pytest-Mock:** Para isolar dependências externas.
- **Selenium WebDriver:** Para automação de testes E2E.
- **Pytest-BDD:** Para testes orientados a comportamento com arquivos `.feature`.
- **GitHub Actions:** Para rodar o pipeline de CI de forma automática.
